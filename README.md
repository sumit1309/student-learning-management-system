# Student Learning Management System

A responsive Learning Management System (LMS) built using React.js to streamline academic management for students.

## Features

- Student Dashboard
- Attendance Tracking
- Course Management
- Faculty Information
- Timetable
- Assignment Module
- Quiz Module
- Marks Management
- Hostel Information

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3

## Project Structure

```
src/
public/
package.json
```
